# What this demo proves

Jev receives the full present-tense token screen: contract controls, taxes, liquidity and removal history, creator and verified-vesting holdings, trading flow, and failed sells. The generator keeps the future outcome outside the state.

Honeypot recall is its own headline measure. Failed sell attempts only become reliable when buys work and almost no sell succeeds; one failure among hundreds of successful sells remains ordinary network noise.

The 18 decoys test causal reading. Concentration in a verified vesting contract is not creator control, and an old unlocked pool that has never moved is not the same as liquidity being removed.

Every token, ticker, address, pool and trade history is invented. This is a screening exercise, not investment advice.

## Recorded run

Jev 1.13.0 answered every one of the 160 tokens on 19 September 2026. Each request carried the full state and all five questions; the run used 204,775 input tokens and 28,705 output tokens. The fixture audit found no missing, extra or malformed records.

The model caught all nine honeypots, constrained every one of the 34 harmful tokens by avoiding it or imposing a small position, and excluded none of the 126 fine tokens. Its derived held-out outcome was right on 151 of 160 (94.4%); nine fine tokens were conservatively called rug-shaped. All 14 later rugs, all 11 tax traps and all nine honeypots landed in the correct outcome row. One verified vesting allocation was named as holder concentration, but the model still kept it tradeable rather than excluding it.
