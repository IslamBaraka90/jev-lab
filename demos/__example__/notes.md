# Example: one journal line

This is the smallest demo that uses every part of the runtime: a dataset with an envelope, a state
builder, three typed questions, an evaluation and a report graded against planted problems.

It is **hidden from the catalog** and exists for two reasons: the foundation tests run against it, and
`npm run dev` has something to render before the real demos are built.

**Its answers are not model output.** They are deterministic stubs from
`scripts/make-example-fixtures.js`, and the fixture file says so in its `source` field. Catalog demos
record their answers from the live API with `scripts/record-demo.js`.

**The data** is thirteen journal lines in seven documents, generated by `scripts/generate/example.js`
from seed 1000. Two problems are planted: document DOC-002 is posted a second time as DOC-006, and one
stationery expense is posted as a credit so its document does not balance. The planted list lives in
`data/synthetic/__example__.labels.json`, outside this folder, so it cannot reach a state.

**The real thing** is PRP 101, which does the same job over 500 lines, five issue types and a
threshold you can move.
